# SketchUp Kitchen Cabinets Plugin

بلاجن احترافي لـ SketchUp يحتوي على مكتبة شاملة لتصميم وبناء الكبائن المطبخية.

## المميزات الرئيسية
- مكتبة كاملة للكبائن وأنواعها المختلفة
- التحكم في المفصلات والأكسسوارات
- محاكاة الفتح والغلق للأبواب والأدراج
- تصاميم متقدمة وقابلة للتخصيص
- نظام التقارير والتصدير
